## 🎮 How to Play

| Action | How |
|--------|-----|
| **Select a cell** | Click it |
| **Switch direction** | Click the same cell again |
| **Type a letter** | Just type — cursor advances automatically |
| **Delete** | Backspace — retreats to previous cell |
| **Navigate** | Arrow keys |
| **Next word** | Tab |
| **Previous word** | Shift + Tab |
| **Check answers** | ✓ CHECK button |
| **Reveal all** | 👁 REVEAL button |
| **Clear board** | ✕ CLEAR button |
| **Reset** | ↺ RESET button |

## 🧩 The Puzzle — ACROSS & DOWN

**ACROSS**
- **1.** Tiny dot on a digital display *(5 letters)*
- **3.** Vintage or old-school in style *(5 letters)*
- **5.** Points tallied in a game *(5 letters)*

**DOWN**
- **1.** To groom oneself with care *(5 letters)*
- **2.** Large public exhibition or fair *(4 letters)*
- **4.** To throw lightly into the air *(4 letters)*

## ✨ Features

- ✅ Retro green pixel art theme
- ✅ Animated title glow effect
- ✅ Checkerboard background
- ✅ Word highlighting when cell selected
- ✅ Real-time progress bar
- ✅ Green ✓ / Red ✗ letter feedback
- ✅ Win screen with animation
- ✅ Keyboard navigation (arrows, Tab, Backspace, Enter)
- ✅ Mobile responsive
- ✅ No backend, no build tools — pure static files

---

## 🛠️ Built With

- **HTML5** — structure & inputs
- **CSS3** — pixel art aesthetic, animations, checkerboard background
- **Vanilla JavaScript** — all game logic (no frameworks)
- **Press Start 2P** — pixel font from Google Fonts
